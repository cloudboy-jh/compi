## Next

   - Done, phase A: the daemon parses reports and answers feature detection, keeps at most 64 records per terminal with the prompt (OSC 133 `A` from the shell bridge), exit, reset and acknowledgement rules, and bounds every OSC string before parsing. Protocol 26 adds `WatchProgramStatus` (current records, then coalesced changes) and `AcknowledgeProgramStatus`. Covered by `daemon_integration` `program_status_reaches_watchers_through_the_pty_and_follows_its_lifecycle` through ConPTY and WSL Bash.
   - Done, phase B: one watching connection per window feeds tab glyphs, tiled-pane dots, floating title strips and the sidebar/palette status line, with hover listing each pane's records; a keypress or typed text in a pane acknowledges its finished results; `[program_status] tabs/panes/sidebar` toggles each place (Settings → Interface → Program status); `compi --json pane list/show` carries `program_status`. Seen in `cargo dev` on Windows/WSL: the blocked glyph on a background tab, hover cards, prompt clearing, keypress acknowledgement, a floating pane at 65%, and status surviving a preview restart. See [Completed work](COMPLETED.md#program-status-osc-7501-phases-a-and-b--2026-10-12).
   - Phase C: check the Settings rows on screen, real programs (Claude Code, Pi) and a GUI reconnect against them, and a Unix twin of the integration test on a Mac.

2. **Settings and cleanup**, feature 3 in the features doc. Keep Compi's look (Comfy islands, iris mark, Neutral theme); borrow behaviour from references, never their layout. One phase per session, checked in `cargo dev`.
   - Done, **3a. Menus, popovers and selects (GPUI Kit).** `controls.rs` wraps Kit's popover, popup menu and a select (no Kit `Root` needed). Both font pickers are one select sized to its value, with a right-aligned list as wide as its longest font, each drawn in itself. The theme catalog's More is a menu, the shell prompt confirm a popover on the clicked control, and Quick Appearance a popover on the sidebar's Appearance button (or the header's sidebar toggle). Overlays skip their fade under reduced motion. Seen in `cargo dev` on Windows except the reduced-motion fade. See [Completed work](COMPLETED.md#menus-popovers-and-selects-phase-3a--2026-10-13).
   - Done, **3b. Right-click and pane controls.** Right-click opens a Kit menu at the pointer for what was clicked (terminal, floating title, header, content pane, Files and Changes rows), never the palette; the editor keeps Kit's menu. One pane action set everywhere (Focus, Move to new tab, Float/Dock pane, End process…, Close pane); End process… always confirms. The tab menu is content-width with a **Panes** group: a row focuses its pane, its × closes it in one click with the menu open, › (hover or click) opens the actions, and ↑↓ Enter Delete → ← Escape work. Tiled panes show ⋯ and × on hover; a float's title shows them in place of Dock. The hand-made action menu and Detach/Float/End strip are gone. Seen in `cargo dev` on Windows except the tab menu's keys. See [Completed work](COMPLETED.md#right-click-and-pane-controls-phase-3b--2026-10-13).
   - Done, **3c. Settings as a pane** (protocol 27, workspace file format 4). `PaneContent` is `Files` or `Settings`, so layout operations treat Settings like any content leaf. Ctrl/Cmd+, opens it beside the focused pane, focuses the window's existing one, or with no tab open gives it a tab of its own (`CreateContentTab`; the empty screen has a Settings button). Search filters every section; a row registry drives sections, search and Tab order, replacing the hand-indexed focus code. The modal is gone. Seen in `cargo dev` on Windows. See [Completed work](COMPLETED.md#settings-as-a-pane-phase-3c--2026-10-13).
   - Done, **3d. Settings pane redesign.** One header line: title (dropped when narrow), section icons (Lucide, name as tooltip) and a search icon that opens the field (click, Ctrl/Cmd+F or typing). Pages use the full pane width (up to 1280 px, centred) with settings in cards, drawn choices for pane density and focus indicator, Kit buttons and switches throughout. Appearance is a compact Window card (opacity on one row) and the full theme grid filling the rest of the pane: columns follow the width, tiles share each row, live preview with a pinned Apply/Cancel bar; the full-window theme catalog is gone. Tiled panes show only the ⋯ grip. Seen in `cargo dev` on Windows (wide, narrow float, preview and cancel). See [Completed work](COMPLETED.md#settings-pane-redesign-phase-3d--2026-10-13).
   - Done, **3e. Drag, floats and motion.** A pane drag lights only the zone under the pointer (half or Swap box). The focused float has an accent border and deeper shadow, no Keyboard label. Dragging a float by its title over a tiled pane shows the same targets and docks it there in one step. Commits (drops, docks, float/dock commands) animate the drawn frames over 150 ms and send one PTY resize when they land; reduced motion is instant. Seen in `cargo dev` on Windows. See [Completed work](COMPLETED.md#drag-floats-and-motion-phase-3e--2026-10-13).
